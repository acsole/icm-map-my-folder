# 1.5 · The Output Templates

**Type + State:** ENGINE · LIVE — `rules.md:37-45` maps four jobs to four templates and says they
"ARE the output structure", followed on every run of those jobs in every market.

**What it is:** the shape of each answer — listing, buyer-fit summary, pricing memo, showing note.
Not a blank to copy: a structure the specialist fills fresh each time.

**Why it is shaped that way:** an agent compares answers across jobs and weeks, so the structure
is fixed in a file rather than left to each run.

**Source path:** `specialist/reference/templates/`

**Hits:** every answer of its job, in every market, from the next run. `showing-note.md` reaches
further: its notes are durable input, cited by tag in later matching runs
(`frameworks/buyer-fit.md:85-89`), so changing its tags strands every note already written.

**Does not hit:** Services lookup — the one job with no template. Its answer follows the rules in
each market's own `region/services.md` (`rules.md:45`), so its shape is per market and a slot, not
here.

**Done when:** you have named the one template your job uses and checked whether it is
`showing-note.md`, whose tags outlive the run. Stop there.
