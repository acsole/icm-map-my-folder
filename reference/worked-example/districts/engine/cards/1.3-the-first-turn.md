# 1.3 · The First Turn

**Type + State:** ENGINE · LIVE — every market's first message runs through it:
`identity.md:36` and `rules.md:35` both send the opening turn here, and its one market name
(`welcome.md:23`, Novato) is an example inside a placeholder.

**What it is:** the opening menu — the five jobs plus "just exploring" — and when to skip it: an
agent who opens with a job or its inputs gets the job, not the menu.

**Why it is shaped that way:** the menu is the only place a new user learns what the specialist
will do, so it is held to the job set. `welcome.md:46` calls it a contract.

**Source path:** `specialist/welcome.md`

**Hits:** every market, immediately — and it reaches into each one: the greeting fills its
location from that market's `region/market.md` (`welcome.md:17`, `:23`), and an empty region pack
replaces the menu with the population flow (`:40`).

**Does not hit:** what a job does. Editing a menu line changes how a job is offered, never how it
runs; routing lives in `rules.md`. A menu line for a job the table does not route is the failure
this file warns about.

**Done when:** you know whether your change is to the offer (here) or to the job (card 1.2), and
you have not opened `rules.md` to find out. Stop there.
