# District 7 — The Public Edge

**Territory:** what someone who never opened the repo can reach — the site Pages serves from
`docs/`, and the root `README.md` GitHub shows every visitor — in
[`NFTYoginis/your-market-realtor`](https://github.com/NFTYoginis/your-market-realtor) at the commit
the [top catalog](../../CATALOG.md) pins.
**Why a district:** one card held the public edge. Every walk on an outsider's question left the map
to read the instructions that move a user's region files across versions, which no card carried; and
the working papers the site publishes had one line on card 07, with one of them linked from nowhere.

**Read the row, then one card. Stop.** If you need a second card, the first was mis-scoped — say so
rather than reading on.
