# 00 · The Pricing Framework (control)

**Type + State:** ENGINE · LIVE — fixture; the state is not what this card tests.
**What it is:** the method that turns nearby sales into a price band, never a single number.
**Why it is shaped that way:** a seller has to be able to disagree with the reasoning, so the
reasoning travels with the band.
**Source path:** `big.md`
**Hits:** every market that reads it, immediately.
**Does not hit:** the list price — that is the seller's decision after reading the band.
**Done when:** you can name the section of `big.md` that governs your case. Stop there.
